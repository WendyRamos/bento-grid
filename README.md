# Frontend Mentor - Bento Grid

Esta es mi solución al desafío **Bento Grid** de [Frontend Mentor](https://www.frontendmentor.io/challenges/bento-grid).

## Vista general

### El desafío

El objetivo es construir un diseño tipo **bento grid** siguiendo el diseño proporcionado por Frontend Mentor y adaptarlo para diferentes tamaños de pantalla.

### Tecnologías utilizadas

* HTML5
* Tailwind CSS
* CSS Grid
* Diseño responsive

### Lo que aprendí

Durante el desarrollo de este proyecto practiqué:

* La creación de layouts utilizando CSS Grid.
* El uso de clases utilitarias de Tailwind CSS.
* La adaptación de interfaces para diferentes tamaños de pantalla.
* La implementación de un diseño a partir de un mockup proporcionado.
